# Ghostex hotkeys reference

Generated by `packages/settings-catalog` from the hotkey catalog. Do not edit by hand; run `cargo xtask help-generate`.

Default bindings are listed for macOS (`cmd`) with the Windows/Linux default where it differs. Users rebind them in Settings > Hotkeys, and agents change them with `ghostex settings hotkeys list`, `ghostex settings hotkeys set <id> <keys>` (`none` unassigns) and `ghostex settings hotkeys reset <id>|--all`; use the Id column below.

While a terminal has the keyboard, the Terminal focused binding applies instead (Settings > Hotkeys > Terminal focused, saved under `terminalHotkeys`). Its defaults equal the normal ones on macOS; on Windows and Linux they leave the plain Ctrl keys to the program in the terminal. Until the Terminal focused binding is set, it follows the normal key when the user changed that, and otherwise the Terminal focused default listed below. Both bindings can be changed or cleared on their own, and the same keys may be used in both. "none" in the Terminal focused column means the hotkey has no Terminal focused binding; "terminal only" in the Default column means it has only that one. Add `--terminal` to `ghostex settings hotkeys list`, `get`, `set` or `reset` for the Terminal focused bindings (Ghostex newer than 10.36.0).
