# ghostex-agent-guide

Run `ghostex agent-guide` and follow it. It says how to show pages, questions
and charts in the chat, which browser to open a page in (the user's saved
choice, or ask them once), how to work with other agents, how to ask for a
secret, which Ghostex skills you can install for the user, and how to ask
Ghostex Help (`ghostex help ask "<question>"`).

If `ghostex agent-guide` is an unknown command, this Ghostex is older: run
`ghostex guide` and `ghostex --help` instead.
