EXP · Chat experience

Turn messages into workflows.

Ghostex’s composer already handles keyboard submission, command completion, history, pasted images, uploaded files, and native file selection. Improve the workflows around it rather than replacing its core immediately.

Design direction

Keep plaintext transport exact. Add structured draft objects, mentions, and actions around it, then serialize only at submission.
