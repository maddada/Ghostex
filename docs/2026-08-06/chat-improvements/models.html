MDL · Providers and models

Discover, do not guess.

Treat the coding agent as a provider and the models beneath it as a live catalog. This prevents Ghostex releases from becoming tied to every model launch, retirement, or account-level entitlement change.

Current baseline

Chat already normalizes Claude, OpenClaude, Codex, Grok, Pi, and OMP. Only Claude-family and Codex currently have static option catalogs.

MDL-01 · P0

Dynamic model discovery service

Add a gxserver endpoint that returns normalized models, supported reasoning levels, input modes, default state, and catalog verification status.

MDL-01A

Per-host cache

Cache by machine, provider, installation, and account context. Refresh with bounded time and clear state.

MDL-01B

Verified state

Distinguish loaded, stale, unavailable, unauthenticated, and failed catalogs.

MDL-01C

Selection safety

Keep a stored model visible until successful discovery proves that it is unavailable.

RULE

Static catalog rows may supply friendly names and descriptions, but they must not be the sole truth about availability.
