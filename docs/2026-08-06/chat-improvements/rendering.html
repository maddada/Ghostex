RND · Rendering

Make the work legible.

The current chat renderer handles prose, links, images, reasoning, tool runs, and a basic edit view. The next layer should make code review, command inspection, and long agent runs feel native rather than generic.

Best near-term package

RND-01 + RND-02 + RND-03 deliver the clearest visible improvement without waiting for the full event migration.

RND-01 · P0

Rich Markdown and code blocks

Evolve the current shared renderer rather than creating a second Markdown path.

RND-01A

Code presentation

Language label, syntax color, per-block copy, wrap toggle, and bounded work for very large blocks.

RND-01B

Rich technical content

KaTeX math, Mermaid diagrams, contained wide tables, and optional soft-break preservation.

RND-01C

Safe routing

Keep local-file and external-link actions host-controlled. Sanitize any raw HTML before math or diagram enhancement.

LEVERAGE

Ghostex already includes syntax and math-related packages, making the first version lower effort than a new renderer from scratch.

Ghostex: sidebar/chat/session-chat-markdown.tsx · package.json

RND-02 · P0

Review-grade file patches

Render exact provider patches where available; do not silently invent context when it is missing.

RND-02A

Unified patch model

Normalize file path, old and new ranges, context lines, additions, deletions, rename state, and binary status.

RND-02B

Diff card

Sticky file header, line numbers, theme-aware rows, collapsed unchanged ranges, and direct open-file action.

Current limitation: sidebar/chat/session-chat-diff.ts reconstructs all deletions before all additions.

RND-03 · P0

ANSI-aware terminal cards

Commands are a first-class work type, not generic tool text.

RND-03A

Command header

Show executable text, working directory, running state, elapsed time, and exit code.

RND-03B

Streamed output

Preserve ANSI meaning, keep the active output edge visible, and allow user-controlled expansion.

RND-03C

Large output

Avoid the current fixed 4,000-character loss. Keep a bounded preview with explicit access to the full stored result.

RND-04 · P1

Semantic activity timeline

Replace the count-plus-label tool fold with a readable hierarchy of turns, work steps, groups, and detail rows.

WORK-CMD

Commands

Process execution, output, status, and exit data.

WORK-FILE

File work

Reads, searches, writes, patches, and affected paths.

WORK-WEB

Research

Searches, fetches, citations, and source state.

WORK-DEL

Delegation

Child-agent assignment, progress, completion, and handback.

WORK-ASK

Interactions

Questions, approvals, selected answers, and denied requests.

WORK-FLOW

Workflows

Goals, plans, tasks, background commands, and compaction.
