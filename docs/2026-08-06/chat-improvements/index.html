Decision guide · 06 August 2026

Make chat feel like a workbench.

Ghostex already has reliable transport, paging, attachments, questions, approvals, and a capable composer. The largest gains now come from richer event semantics, dynamic model discovery, and rendering that makes agent work easy to follow.

How to discuss this report

Every proposal has a stable code. Refer to FND-01 or RND-04 instead of restating the whole idea.

00 / Thesis

The interface is downstream of the data.

A visual redesign alone will still receive flattened text and generic tool rows. The durable improvement is a typed event stream and a provider capability layer, followed by focused rendering upgrades.

03 / Preserve

Do not rebuild the strong parts.

The new design should preserve Ghostex’s established reliability and shared-surface architecture.

KEEP-01

Transport resilience

Keep sequence and epoch handling, gap recovery, transcript resync, and optimistic reconciliation.

KEEP-02

Composer mechanics

Keep keyboard behavior, command completion, prompt recall, image paste, and native file selection.

KEEP-03

Interactive prompts

Keep the existing question and approval card foundation, then enrich provider-specific choices.

KEEP-04

Shared desktop and web surface

Continue injecting host capabilities instead of creating separate chat implementations.

KEEP-05

Pagination and scroll anchoring

Retain current history paging and stable prepend behavior as search and navigation are added.

KEEP-06

Terminal access

Structured chat should complement the terminal and preserve direct access when users need it.
