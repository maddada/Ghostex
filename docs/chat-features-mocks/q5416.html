3. Which Jira

Jira Cloud signs in with an email and an API token. Jira Data Center (a company's own server) uses a personal access token and no email, and its issue text is in an older format.

Jira Cloud only for nowSmaller and fully testable; Data Center can follow as its own item. Jira Cloud and Data CenterLeave Email empty to use a Data Center personal access token.
